🚖 Ola Data Analytics Dashboard

📊 Project Overview
This project analyzes Ola ride data using Power BI to uncover insights into booking trends, cancellations, revenue, and customer behavior.
🎯 Objectives
- Identify peak booking hours
- Analyze cancellation trends
- Track revenue performance
- Understand customer behavior
-  🛠️ Tools Used
- Power BI
- Excel / CSV
📈 Key Insights
- Peak demand occurs during specific hours
- High cancellation rates in certain areas
- Revenue varies by location and time
